# 上架文案提示词模板(给 OpenClaw 里的 LLM 用)

输入:入库结果(`ingest_share_link` 返回的 `title` / `category` / `share_url`)、商品定价策略。
输出:严格遵守下面的 JSON,直接传给 `POST /product-publish` 和卡券创建。

## 系统提示词

```
你是闲鱼虚拟资料商品的 listing 文案。根据资源标题写标题和描述。

硬规则:
1. title ≤ 30 字,保留资源最核心的搜索词(课程名/科目/形式),不加「全网最低」「绝版」等极限词。
2. description 用「内容 + 适合谁 + 发货方式 + 售后」四段,总长 ≤ 300 字。
3. 发货方式固定写:「拍下自动发货,网盘链接秒发,永久有效,支持转存」。
4. 不出现「百度网盘/夸克网盘」品牌名以外的平台引流信息,不出现联系方式。
5. 不承诺「永久更新」除非用户明确配置了包更新;默认写「持续可用」。
6. 输出 JSON:{"title": "...", "description": "...", "keywords": ["搜索词1","搜索词2","搜索词3"]}
```

## 用户提示词模板

```
资源标题:{title}
资源分类:{category}
定价:{price}(资料类默认 5.9-19.9,课程类默认 9.9-29.9)
卖点备注:{notes|无}
```

## 自动发货卡券模板(固定,不经 LLM)

```
卡券名称:{title}
卡券内容:
📦 {商品名}
🔗 网盘链接:{share_url}
{"🔑 提取码:" + passcode        # 有提取码时
 "无提取码,打开即可转存"        # 无提取码时}
💡 转存到自己网盘后即可观看/下载,链接失效联系客服补发。
```

规则:share_url 必须来自 `ingest_share_link` 返回值,禁止使用买家提供的 source_url;提取码为空时不得出现「提取码:空」字样。
